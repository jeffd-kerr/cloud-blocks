# ☁️ Cloud Tetris

A modern twist on the classic Tetris game where pieces **float upward** instead of falling down!

## Play Now

🎮 **[Play Cloud Tetris](https://jeffd-kerr.github.io/cloud-tetris/)**

## How to Play

- **Pieces float UP** from the bottom of the screen
- Create **complete horizontal lines** before the board fills up
- Lines disappear in a burst of colorful particles
- Each level gets faster!

## Controls

| Key | Action |
|-----|--------|
| ← → | Move piece left/right |
| ↑ or Z | Rotate clockwise |
| ↓ or X | Rotate counter-clockwise |
| SPACE | Drop instantly to top |

## Features

✨ **Beautiful cloud-themed design** with puffy gradient blocks
🎵 **Dynamic sound effects** (synthesized Web Audio)
🌟 **Smooth animations** — float trails and pop particles
📊 **Score tracking** with levels and line counting
🎨 **7 unique Tetris pieces** with soft pastel colors

## Technical

- Pure **HTML + Canvas + JavaScript**
- No dependencies, no build step
- Works offline
- ~33KB single file
- Web Audio API for sound
